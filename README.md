# www.monaidea.com

Basic landing page for Monaidea, the public name of VestaNabu LLC's software products (owner, 2026-10-21). Served by GitHub Pages from `main` (custom domain in `CNAME`). The product sites are https://ledgerstone.monaidea.com (repo VestaNabu-LLC/ledgerstone-site, named atlapps until 2026-10-25) and https://flagstone.monaidea.com (repo VestaNabu-LLC/flagstone-site, in development). `style.css` and `site.js` are copies of the Flagstone site's files (Ledgerstone's, plus a few additions at the end).

What Monaidea is will be defined later with the owner; until then the page only names the company, links both apps (Flagstone marked in development) and gives the support address. VestaNabu LLC appears only in the copyright line.

Contact form (owner request, 2026-11-02): the `#contact` section of the home page and `contact.js`; every page's "Contact" link goes there, and support@monaidea.com stays visible as plain text. The form posts to Monaidea's own contact Worker, `monaidea-contact` in Monaidea's Cloudflare account at https://forms.monaidea.com (source, tests and settings in `worker/`; the owner creates and deploys it in the dashboard, and `GET https://forms.monaidea.com/` shows whether its two secrets are set). It checks Cloudflare Turnstile (Monaidea's widget, in the same account; its public site key is `SITEKEY` in contact.js) and emails the message from noreply@monaidea.com to support@monaidea.com through Postmark. Turnstile loads only once someone starts using the form. Tests: `node --test worker/test/*.test.mjs`. Any https://*.monaidea.com page can use the same Worker.
