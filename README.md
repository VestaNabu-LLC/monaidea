# www.monaidea.com

Basic landing page for Monaidea, the public name of VestaNabu LLC's software products (owner, 2026-10-21). Served by GitHub Pages from `main` (custom domain in `CNAME`). The product sites are https://ledgerstone.monaidea.com (repo VestaNabu-LLC/ledgerstone-site, named atlapps until 2026-10-25) and https://flagstone.monaidea.com (repo VestaNabu-LLC/flagstone-site, in development). `style.css` and `site.js` are copies of the Flagstone site's files (Ledgerstone's, plus a few additions at the end).

What Monaidea is will be defined later with the owner; until then the page only names the company, links both apps (Flagstone marked in development) and gives the support address. VestaNabu LLC appears only in the copyright line.

Contact form (owner request, 2026-11-02): the `#contact` section of the home page and `contact.js`; every page's "Contact" link goes there, and support@monaidea.com stays visible as plain text. The form posts to VestaNabu LLC's contact Worker on Cloudflare (`vestanabu-contact`, source and tests in VestaNabu-LLC/webforvestanabullc under `worker/`; the owner deploys it), which checks Cloudflare Turnstile (the www.vestanabullc.com widget, with monaidea.com added to its hostnames) and emails the message to support@monaidea.com through Postmark. Turnstile loads only once someone starts using the form. Any https://*.monaidea.com page can use the same form without a Worker change.
